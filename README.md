# 智能体微信提醒

任务进展 随时掌握

Windows 10/11 x64 桌面软件，提供智能体完成、失败和待回复微信通知。

## 下载与授权

请从 [Releases](https://github.com/HelloGit403/agent-wechat-reminder-releases/releases) 下载正式安装包。
软件需要对应设备的有效离线许可证。公开下载安装包不等于获得使用授权。

这是安装包和版本信息的发布仓库。源码、签发工具、私钥、用户信息不在此仓库发布。
通知依赖网络与微信服务可用性，接口接受不代表手机必然收到。

## 更新

在软件设置的“关于与更新”中手动检查，再打开官方发布页面下载。
安装确认后可自动关闭旧程序并覆盖升级，保留个人设置与授权。
